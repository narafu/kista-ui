Option A — 카드 상태 전환 흐름

실행 전 → 실행 후 → (개별/전체 취소) 세 상태를 보여줍니다

① 실행 전 (현재 유지)
다음 주문 미리보기 INFINITE
2026-06-02 예정
매수TQQQ 3주LOC
매도SOXL 5주LOC
→
실행 성공
orders[] 반환
POST /trading-cycles
/{id}/execute
→ {orders:[{id,…}]}
② 실행 후 (취소 가능)
다음 주문 미리보기 접수됨
✓ 2건 접수됨
매수 TQQQ 3주
매도 SOXL 5주

취소 결과별 처리

✓ 전체 취소 성공
cancelledCount=2, failedCount=0
toast: "2건 모두 취소됐습니다"
→ 카드가 미리보기 모드로 복귀
⚠ 부분 실패
cancelledCount=1, failedCount=1
toast: "1건 취소, 1건 실패"
→ 실패한 주문은 목록에 유지
(서버에서 어느 건 실패인지 알 수 없어 전체 재조회)
✕ 개별 취소
DELETE /api/orders/{orderId} → 204
해당 행만 목록에서 제거
→ 모두 제거되면 미리보기 복귀
⚠ 백엔드 추가 변경 필요
현재 POST /api/trading-cycles/{id}/execute는 202 반환 시 body 없음.
개별 취소에 필요한 orderId를 얻으려면 응답 body에 생성된 주문 목록 추가 필요:
{ "orders": [{ "id": "uuid", "ticker": "TQQQ", "direction": "BUY", "quantity": 3, "price": "52.40", "orderType": "LOC" }] }
