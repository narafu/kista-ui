# widgets/dashboard

- **`dashboard`**: `/dashboard`는 비회원도 접근 가능한 유일한 `(main)` 경로다(`proxy.ts`의 `PROTECTED_PREFIXES`에 없음). `app/(main)/dashboard/page.tsx`가 `isAuthenticated`(`hasValidToken(token)`)를 계산해 `DashboardContent`·`WeeklyMarketCalendar`에 prop으로 내려주고, 휴장일(`monthlyHolidaysQueryOptions`, public 엔드포인트)은 항상, 계좌 목록은 인증 시에만 prefetch+hydrate한다. `DashboardContent`·`WeeklyMarketCalendar`는 `isAuthenticated` prop으로 계좌 쿼리를 게이팅한다(근거·루프 위험은 `docs/agents/architecture.md` 레이아웃 그룹). `WeeklyMarketCalendar`·`FearGreedSection`은 `widgets/dashboard`가 직접 import하지 않는다 — 페이지가 `marketPanels`(ReactNode) slot으로 조립해 `DashboardContent → DashboardEmpty`/`DashboardOverview`로 그대로 흘려보낸다. 시장 패널·차트는 `DashboardMarkets`가 PC·모바일 공용 트리 하나(패널 줄 `lg:grid-cols-3`, 차트 줄 `lg:grid-cols-3`)로 렌더한다 — `hidden lg:block`/`lg:hidden`으로 두 벌 마운트하면 차트 인스턴스·토글 상태가 중복되므로, 브레이크포인트별 내용이 실제로 다른 안내 카드·헤더만 분기한다. 계좌 조회 실패 시 `throw`하지 않고 `DashboardOverview`의 `notice`로 안내만 얹는다(Empty로 떨어지면 기존 사용자에게 첫 계좌 등록을 권하게 된다). 스켈레톤은 `DashboardSkeleton` 하나를 라우트 `loading.tsx`와 계좌 조회 대기가 공유한다
