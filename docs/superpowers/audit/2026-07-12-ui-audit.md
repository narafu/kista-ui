## 정적 코드 감사 (S-nn)

Task 0.5 — 스크린샷으로 판정 불가능했던 A-nn 항목을 파일:라인 증거로 확정하고, `grep` 기반 정적 검색으로 추가 항목을 수집했다. `/pending`·`/rejected`는 ACTIVE 세션에서 캡처 불가해 코드 리딩으로 대체했다.

### A-nn 항목 해소 (증거 기반 확정)

| ID | 파일:라인 | 판정 |
|---|---|---|
| A-01 | `proxy.ts:76-79`, `app/(auth)/page.tsx:1-6` | **버그 확정**. `proxy.ts`는 비인증 상태에서 `token`이 없으면 `pathname === '/'`일 때 무조건 `redirectTo('/dashboard', ...)` 한다(77-79행) — 문서(`docs/agents/architecture.md`)가 명시하는 "비인증 → `/`" 규칙과 정면 배치. 게다가 `app/(auth)/page.tsx`는 인증 여부를 전혀 확인하지 않고 `redirect('/dashboard')`를 무조건 실행하는 폴백 — proxy를 고쳐도 이 페이지가 동일 버그를 재현한다. 두 곳 모두 수정 필요 |
| A-27 | `proxy.ts:214-219` (`routeByStatusAndRole`) | **의도된 동작 확인**. `status === 'ACTIVE'`이고 `pathname === '/login'`이면 `/dashboard`로 리다이렉트한다(215-217행) — ACTIVE 사용자가 `/login`에 직접 접근해도 즉시 대시보드로 밀려나는 정상 분기. A-01과 달리 버그 아님 |
