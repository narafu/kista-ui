# 관리자 P 매매표 모바일 정렬 디자인

## 목표

관리자 `P 매매표`에서 모바일 구간만 `날짜`, `종목`, `시작금액`, `보유` 컬럼이 콘텐츠 길이에 가깝게 붙도록 정리한다.

## 범위

- 대상: `widgets/admin-privacy-trade-list/AdminPrivacyBaseTable.tsx`
- 대상 뷰포트: 모바일 기본 구간
- 비대상: `sm` 이상 데스크톱 레이아웃, 펼침 상세 주문 테이블 구조

## 요구사항

1. 모바일에서 `날짜`, `종목`, `시작금액`, `보유` 컬럼의 폭 고정값을 제거한다.
2. 모바일에서 위 4개 헤더는 모두 가운데 정렬한다.
3. 모바일에서 데이터 정렬은 `날짜`, `종목`, `보유`는 가운데 정렬, `시작금액`만 오른쪽 정렬한다.
4. `sm` 이상에서는 기존 정렬과 레이아웃을 유지한다.
5. 기존 모바일 헤더 축약(`시작금액`)은 유지한다.

## 접근 방식

- 테이블은 계속 단일 `<table>` 구조를 유지한다.
- 모바일 기본 클래스와 `sm:` 오버라이드를 분리해 정렬 규칙을 뷰포트별로 제어한다.
- 회귀 방지를 위해 Vitest로 헤더/셀 정렬 클래스와 모바일 폭 고정 제거를 검증한다.

## 테스트

- `widgets/admin-privacy-trade-list/AdminPrivacyBaseTable.test.tsx`에서
  - 모바일 헤더 4개가 가운데 정렬인지
  - `시작금액` 셀만 오른쪽 정렬인지
  - 모바일 폭 고정 클래스가 제거됐는지 확인한다.
