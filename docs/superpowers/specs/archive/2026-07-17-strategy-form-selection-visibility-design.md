# 선택형 카드 상태 가시성·일관성 개선

## 배경

전략 등록·수정 폼의 선택형 컨트롤은 선택된 항목이 옅은 배경과 브랜드색 텍스트로만 구분된다. 다크 모드에서는 비선택 항목의 밝은 본문색이 더 강하게 보여 선택 항목이 오히려 뒤로 물러난다. 전략 유형, 종목, 분할 수, 시드 모드, VR 옵션이 서로 다른 선택 표현을 사용하는 점도 빠른 상태 인지를 방해한다.

설정 화면도 같은 문제가 있다. 알림 수단은 얇은 테두리와 색이 약한 텍스트만 사용하지만 테마 선택은 2px 테두리와 체크를 사용한다. 두 UI가 독립 구현되어 같은 화면 안에서도 선택 상태 문법이 다르며, 알림 수단은 다크 모드 화면에 고정 라이트 팔레트 토큰을 직접 사용한다.

## 목표

- 사용자가 폼을 훑을 때 현재 선택을 즉시 구분할 수 있어야 한다.
- PC와 모바일, 라이트와 다크 모드에서 같은 선택 규칙을 사용한다.
- 전략 폼과 설정 화면이 같은 선택 상태 계약과 공통 UI를 사용한다.
- 기존 KISTA의 절제된 로즈 골드 톤과 레이아웃은 유지한다.
- 선택, 키보드 포커스, 비활성, 읽기 전용 상태를 서로 구분한다.

## 범위

다음 선택형 컨트롤의 시각 규칙을 통일한다.

- 매매 전략 유형
- 분할 수
- 종목
- 사이클 시드 모드
- VR 적립 방식
- VR 밴드 폭
- VR 리밸런싱 주기
- 알림 수단
- 테마

전략 등록과 수정 화면에 공통 적용하고 설정 화면의 선택형 카드까지 같은 규칙으로 통합한다. 시드 금액 입력, 퍼센트 게이지, 스위치, 일반 입력 필드의 동작이나 데이터 흐름은 변경하지 않는다.

## 선택된 디자인

사용자가 선택한 `A. 선명한 외곽선` 방식을 적용한다.

### 선택됨

- 2px 브랜드색 테두리로 카드의 전체 윤곽을 표시한다.
- 카드 내부는 옅은 브랜드 틴트로 채우되 텍스트 가독성을 해치지 않는다.
- 주요 텍스트와 아이콘은 테마별 브랜드 전경색을 사용한다.
- 얕은 브랜드색 외곽 링을 더해 주변 카드와의 경계를 강화한다.
- 설명을 포함한 큰 카드는 우측 하단에 체크를 추가해 테마 카드의 기존 명확한 상태 표시를 계승한다.
- 작은 세그먼트는 콘텐츠 공간을 보존하기 위해 체크를 추가하지 않는다.
- 완전 채움 배경은 사용하지 않는다.

### 선택 안 됨

- 1px 기본 테두리와 중립 카드 배경을 사용한다.
- 주요 텍스트는 기본 전경색 또는 기존 정보 계층에 맞는 중립색을 사용한다.
- hover 가능한 항목만 테두리와 텍스트를 가볍게 강조한다.

### 포커스와 비활성

- `aria-pressed`를 유지해 선택 상태를 보조 기술에 전달한다.
- `focus-visible`은 선택 링과 구분되는 명확한 키보드 포커스 링을 표시한다.
- 비활성 항목은 선택 여부를 보존하면서 투명도와 커서로 조작 불가를 표현한다.
- 수정 화면의 고정/읽기 전용 카드는 기존 의미를 유지하며 선택 가능한 카드처럼 보이지 않게 한다.

## 구현 구조

선택 카드의 상태 표현을 `shared/ui`의 작은 공통 UI 컴포넌트로 추출해 전략 폼, 알림 수단, 테마가 같은 구현을 사용하게 한다. 공통 컴포넌트는 선택 상태의 시각·접근성 계약만 담당하고 전략, 알림, 테마의 도메인 데이터와 이벤트는 알지 않는다.

각 섹션은 현재 상태 계산과 이벤트 처리만 유지하고, 선택 버튼은 동일한 상태 계약을 사용한다.

- `selected`: 현재 선택 여부
- `disabled`: 로딩, 수정 불가, 런타임 설정 제한 여부
- `onClick`: 기존 상태 변경 함수
- `showIndicator`: 설명형 큰 카드의 체크 표시 여부
- 크기와 내부 콘텐츠: 전략 카드, 단일 행 옵션, 보조 설명 포함 옵션에 맞게 조절

폼 상태, 유효성 검사, API payload에는 변화가 없다.

## 반응형 동작

### PC

- 기존 열 수와 다이얼로그 폭을 유지한다.
- 넓은 전략 카드와 시드 모드 카드에서도 2px 테두리와 외곽 링이 온전히 보이도록 컨테이너 간격을 확보한다.
- 알림 수단은 4열로 정렬해 카드 폭과 상태 표시 위치를 일정하게 유지한다.
- 마우스 hover는 비선택·활성 항목에서만 제공한다.

### 모바일

- 모든 선택 버튼의 터치 높이를 최소 44px로 유지한다.
- 알림 수단은 2열로 배치해 설명과 체크가 겹치지 않게 한다.
- 3열·4열 선택지에서 2px 테두리가 내부 콘텐츠를 밀거나 잘리지 않게 `box-sizing`과 간격을 유지한다.
- 긴 텍스트나 가격 보조 정보가 있는 종목 카드가 좁은 화면에서 넘치지 않게 한다.
- 드로어 내부 가로 스크롤을 만들지 않는다.

## 테마

선택 상태 전용 시맨틱 토큰을 라이트·다크에 각각 정의하고 공통 UI에서만 소비한다. 다크 모드에 고정 로즈 팔레트 값을 직접 사용하지 않는다. 전략 폼과 알림 수단의 기존 인라인 선택 색상은 제거한다.

## 테스트와 검증

- 기존 선택 동작 테스트를 유지한다.
- 공통 선택 UI 또는 대표 섹션에서 `aria-pressed`, disabled, 클릭 동작을 검증한다.
- 전략 유형, 분할 수, 종목, 시드 모드, VR 옵션의 선택 스타일 적용을 확인한다.
- 알림 수단과 테마가 공통 선택 UI를 사용하며 설명형 카드에 체크가 표시되는지 확인한다.
- `npm run typecheck`와 관련 Vitest를 실행한다.
- React 변경 후 `npx react-doctor@latest --verbose --diff`로 회귀를 확인한다.
- Playwright로 모바일과 PC에서 등록·수정 폼을 확인한다.
- 라이트·다크 모드에서 선택/비선택/비활성/키보드 포커스 상태를 시각 검토한다.
- 모바일 드로어와 PC 다이얼로그에 가로 스크롤이 없는지 확인한다.

## 완료 기준

- 모든 범위 내 선택형 컨트롤이 동일한 `선명한 외곽선` 규칙을 따른다.
- 전략 폼, 알림 수단, 테마 사이에 선택 상태의 테두리·배경·텍스트·체크 규칙이 일관된다.
- 선택된 항목이 비선택 항목보다 테두리, 배경, 텍스트에서 명확히 우세하다.
- 선택 표시가 키보드 포커스 및 disabled 표시와 혼동되지 않는다.
- PC·모바일과 라이트·다크 모드에서 레이아웃 회귀가 없다.
- 폼 데이터와 저장 동작에는 변화가 없다.
