# 통계 페이지 모바일 레이아웃 개선 설계

날짜: 2026-07-18
범위: `kista-ui`의 `widgets/stats-overview`

## 목적

통계 페이지의 데스크톱 비교 성능은 유지하면서 모바일에서 수치의 의미를 빠르게 파악하고 가로 넘침 없이 탐색할 수 있게 한다. 특히 현재 표처럼 보이지만 헤더가 없는 사이클 성과 목록에 명시적인 열 헤더를 추가한다.

## 반응형 정보 구조

기준 중단점은 프로젝트의 기존 Tailwind `sm` 중단점을 사용한다.

- `sm` 이상: 전략 유형 비교와 사이클 성과를 열 헤더가 있는 표로 표시한다.
- `sm` 미만: 두 데이터 집합을 라벨이 붙은 요약 행으로 표시한다. 각 항목은 하나의 평평한 목록 행이며 중첩 카드를 만들지 않는다.
- 데스크톱과 모바일 표현은 같은 조회 결과를 공유하며 API, 쿼리 키, 페이지네이션 동작은 변경하지 않는다.

## 구성 요소별 변경

### KPI

- 모바일의 세로 길이를 줄이기 위해 세 개의 KPI를 조밀한 반응형 그리드로 배치한다.
- 긴 금액과 보조 문구가 컨테이너를 넘지 않도록 최소 너비와 줄바꿈을 점검한다.
- 수치, 색상, 설명 문구는 변경하지 않는다.

### 누적 자산 추이

- 모바일에서 카드와 차트의 좌우 여백, Y축 폭을 줄여 실제 그래프 영역을 확보한다.
- 기간 선택기는 한 줄에서 안정적으로 유지되도록 각 선택지의 폭과 터치 영역을 정리한다.
- 범례와 설명은 자연스럽게 줄바꿈되며 차트나 필터를 가리지 않아야 한다.

### 전략 유형 비교

- 데스크톱 표와 기존 열은 유지한다.
- 모바일에서는 전략 배지를 머리 정보로 두고 `사이클`, `승률`, `평균 수익률`, `평균 소요일`, `실현손익`, `미실현`을 라벨-값 쌍으로 표시한다.
- 손익 색상과 숫자 포맷은 기존 로직을 그대로 사용한다.

### 사이클 성과

- 데스크톱에서는 `전략`, `종목`, `기간`, `손익`, `수익률`, `소요일` 헤더를 추가하고 각 데이터 셀을 같은 열에 정렬한다.
- 모바일에서는 전략과 종목을 첫 줄에 표시하고, 기간과 진행 상태를 그 아래에 둔다. 손익, 수익률, 소요일은 명시적인 라벨과 함께 정렬한다.
- 전략 필터는 모바일에서 한 줄 가로 스크롤로 배치해 전략 유형 수가 늘어도 카드 헤더 높이가 변하지 않게 한다. 선택 상태와 동작은 유지한다.
- 더 보기 버튼과 로딩/빈 상태는 두 표현에서 동일하게 동작한다.

## 접근성

- 데스크톱 데이터는 실제 `table`, `thead`, `tbody`, `th`, `td` 마크업을 사용한다.
- 모바일 표현의 라벨은 시각적으로 항상 노출해 수치 의미를 색상이나 위치에만 의존하지 않는다.
- 필터와 기간 버튼은 기존 키보드 조작 및 선택 상태를 유지하고 모바일에서 충분한 터치 영역을 확보한다.

## 테스트 및 검증

- 위젯 테스트에 사이클 성과의 데스크톱 열 헤더와 모바일 라벨이 렌더링되는지 추가한다.
- 기존 통계 정상, 오류, 빈 상태 테스트가 계속 통과해야 한다.
- `npm run typecheck`와 관련 Vitest를 실행한다.
- 로컬 페이지를 375px 모바일과 데스크톱 뷰포트에서 캡처해 가로 넘침, 텍스트 겹침, 차트 크기, 필터 배치를 확인한다.

## 제외 범위

- 통계 API, DTO, 집계 산식, React Query 데이터 흐름 변경
- 새로운 통계 지표 또는 필터 추가
- 통계 페이지 밖의 공용 카드나 전역 디자인 시스템 개편
