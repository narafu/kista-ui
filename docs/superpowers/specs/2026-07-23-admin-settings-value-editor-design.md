# 관리자 설정 복수값 편집기 설계

## 목적

관리자 설정의 쉼표 구분 텍스트 입력을 구조화된 편집기로 교체한다. 관리자는 허용값과 기본값의 관계를 한눈에 확인하고, 구분자 누락·빈 값·중복·잘못된 숫자 같은 입력 오류를 저장 전에 방지할 수 있어야 한다.

## 범위

- 관리자 설정 페이지의 모든 설정을 확인하되 복수 허용값 필드만 편집 방식을 변경한다.
- 가입 승인, 증권사 등록, 전략 생성 토글은 현재 구조를 유지한다.
- API 요청 및 응답의 `allowedValues`, `defaultValue`, `customizable` 구조는 변경하지 않는다.
- ETF 벤치마크 설정은 주택 대비 성과 비교에서 사용되므로 유지한다.

## 필드별 표현

| 필드 | 편집 방식 |
| --- | --- |
| ETF 벤치마크 자산 | 검색 가능한 문자열 값 목록 편집기 |
| INFINITE 종목 | 종목 메타데이터 검색이 가능한 값 목록 편집기 |
| INFINITE 분할 수 | 숫자 값 목록 편집기 |
| PRIVACY 종목 | 읽기 전용 고정값 |
| VR 종목 | 읽기 전용 고정값 |
| VR 정기 입출금 방식 | 고정 후보 체크박스와 기본값 라디오 |
| VR 밴드 폭 | 숫자 값 목록 편집기 |
| VR 주기 | 숫자 값 목록 편집기 |

## 값 목록 편집기

- 허용값을 한 행씩 표시한다.
- 각 행은 값, 기본값 라디오, 삭제 아이콘 버튼으로 구성한다.
- 하단 입력란에서 값을 입력하고 추가 버튼 또는 Enter로 확정한다.
- 문자열 값은 앞뒤 공백을 제거하고 종목 코드 성격의 필드는 대문자로 정규화한다.
- 숫자 필드는 모바일 숫자 키패드를 사용하고 유한한 숫자만 허용한다.
- 빈 값과 중복값은 목록에 추가하지 않고 입력란 가까이에 즉시 오류를 표시한다.
- 기본값 행은 삭제할 수 없다. 삭제하려면 먼저 다른 행을 기본값으로 지정해야 한다.
- 허용값은 최소 한 개를 유지한다.
- 기본값은 별도 자유 입력으로 받지 않고 목록의 라디오로만 변경한다.

목록은 10개 이하를 전제로 스크롤이나 페이지네이션 없이 모두 노출한다. INFINITE 종목 입력은 앱의 종목 메타데이터를 검색 후보로 제공한다. ETF 벤치마크는 사용자 정의 심볼을 허용하므로 현재 목록을 검색하면서 새 심볼도 직접 추가할 수 있다. 두 경우 모두 선택하거나 입력한 값을 즉시 구조화된 행으로 확정하여 쉼표 입력을 제거한다.

## 정기 입출금 방식

- `DEPOSIT`, `HOLD`, `WITHDRAW` 세 후보를 항상 노출한다.
- 체크박스로 허용 여부를 변경하고, 허용된 항목 중 하나를 라디오로 기본값 지정한다.
- 기본값인 항목은 체크 해제할 수 없다. 먼저 다른 기본값을 선택하도록 안내한다.
- `사용자 변경`을 끄면 기존 정책과 동일하게 `HOLD`만 허용하고 기본값도 `HOLD`로 맞춘다.
- 화면에는 코드와 함께 입금, 거치, 인출 라벨을 표시한다.

## 사용자 변경 토글

- 켜짐: 허용값 목록과 기본값을 편집할 수 있다.
- 꺼짐: 기존 동작대로 기본값 하나만 허용값으로 남긴다.
- 토글을 끌 때 여러 허용값이 제거된다는 점을 짧은 확인 대화상자로 알린다. 허용값이 이미 하나라면 확인 없이 적용한다.
- 고정 필드는 토글과 편집 컨트롤을 표시하지 않는다.

## 오류와 저장

- 입력 단계 오류는 해당 추가 입력란 아래에 즉시 표시한다.
- 설정 간 관계 오류는 기존 `validateAdminSettings`가 저장 전에 최종 방어한다.
- 저장을 시도했을 때 관계 오류가 있으면 저장을 차단하고 첫 오류 메시지에 연결된 필드로 포커스를 이동한다.
- 서버 저장 실패 처리와 변경 취소 동작은 기존 mutation 흐름을 유지한다.

## 컴포넌트 경계

- `ValueListEditor<T>`: 문자열·숫자 허용값 목록, 기본값 선택, 추가, 삭제를 담당한다.
- `RecurringModeEditor`: 고정 enum 후보의 허용 여부와 기본값을 담당한다.
- `FieldEditor`: 사용자 변경 토글과 필드 레이아웃을 담당하고 값 종류에 따라 위 편집기를 조합한다.
- 고정값 표현은 기존 읽기 전용 스타일을 유지한다.

## 반응형 및 접근성

- 모바일에서는 값 행을 한 열로 유지하며 값 영역이 남은 폭을 차지한다.
- 삭제는 휴지통 아이콘과 `aria-label`을 사용하고 최소 44px 터치 영역을 확보한다.
- 기본값 라디오는 그룹 이름과 각 값의 접근 가능한 라벨을 제공한다.
- Enter 추가를 지원하되 버튼으로도 동일한 동작을 제공한다.
- 다크모드는 기존 시맨틱 색상 토큰을 사용한다.

## 테스트

- 문자열과 숫자 값 추가
- Enter 및 추가 버튼 동작
- 공백, 중복, 비정상 숫자 차단
- 기본값 변경과 기본값 삭제 차단
- 일반 값 삭제와 최소 한 개 유지
- 정기 입출금 방식 허용값 및 기본값 변경
- 사용자 변경 비활성화 시 단일 기본값으로 축소
- 변경 취소와 저장 payload 회귀
- 모바일 레이아웃과 다크모드 시각 확인
