# PWA Setup Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** kista-ui를 PWA로 구성해 iOS 홈 화면 추가 후 푸시 알림 수신이 가능하게 한다.

**Architecture:** `sips`(macOS 내장)로 기존 `logo.png`에서 정사각형 아이콘 3종을 생성하고, Next.js App Router의 `app/manifest.ts`로 웹 매니페스트를 서빙한다. `app/layout.tsx`에 iOS 필수 메타태그를 추가한다.

**Tech Stack:** Next.js 15 App Router, sips (macOS built-in image tool), TypeScript

---

### Task 1: 아이콘 생성

**Files:**
- Create: `public/icon-512.png`
- Create: `public/icon-192.png`
- Create: `public/apple-touch-icon.png`

- [ ] **Step 1: 512×512 아이콘 생성**

```bash
cd /Users/phs/workspace/kista/kista-ui
sips --resampleWidth 340 public/logo.png --out /tmp/logo_lg.png
sips --padToHeightWidth 512 512 /tmp/logo_lg.png --padColor FCEFE8 --out public/icon-512.png
```

Expected: `public/icon-512.png` 생성, 크기 확인
```bash
sips -g pixelWidth -g pixelHeight public/icon-512.png
# pixelWidth: 512
# pixelHeight: 512
```

- [ ] **Step 2: 192×192 아이콘 생성**

```bash
sips --resampleWidth 128 public/logo.png --out /tmp/logo_md.png
sips --padToHeightWidth 192 192 /tmp/logo_md.png --padColor FCEFE8 --out public/icon-192.png
```

Expected:
```bash
sips -g pixelWidth -g pixelHeight public/icon-192.png
# pixelWidth: 192
# pixelHeight: 192
```

- [ ] **Step 3: 180×180 apple-touch-icon 생성**

```bash
sips --resampleWidth 120 public/logo.png --out /tmp/logo_sm.png
sips --padToHeightWidth 180 180 /tmp/logo_sm.png --padColor FCEFE8 --out public/apple-touch-icon.png
```

Expected:
```bash

# pixelWidth: 180
# pixelHeight: 180
```

- [ ] **Step 4: 커밋**


```typescript
        sizes: '192x192',
        type: 'image/png',

      {
        src: '/icon-512.png',
        sizes: '512x512',
        type: 'image/png',
        purpose: 'any maskable',
```

### Task 3: iOS 메타태그 추가

**Files:**
- Modify: `app/layout.tsx`

- [ ] **Step 1: `app/layout.tsx` metadata 업데이트**

현재 코드:
```typescript
export const metadata: Metadata = {
  title: "KISTA",
  description: "한국투자증권 KIS API 기반 해외주식 자동 분할매매 SaaS",
};
```

변경 후:
```typescript
export const metadata: Metadata = {
  title: 'KISTA',
  description: '한국투자증권 KIS API 기반 해외주식 자동 분할매매 SaaS',
  manifest: '/manifest.webmanifest',
  icons: {
    apple: '/apple-touch-icon.png',
  },
  appleWebApp: {
    capable: true,
    statusBarStyle: 'default',
    title: 'KISTA',
  },
}
```

- [ ] **Step 2: 타입 검사**

```bash
npm run typecheck
```

Expected: 오류 없음

- [ ] **Step 3: 메타태그 렌더링 확인**

dev 서버 기동 상태에서:
```bash
curl -s http://localhost:3000 | grep -E "manifest|apple"
```

Expected: 다음 태그들이 포함된 출력
```
<link rel="manifest" href="/manifest.webmanifest"/>
<link rel="apple-touch-icon" href="/apple-touch-icon.png"/>
<meta name="apple-mobile-web-app-capable" content="yes"/>
<meta name="apple-mobile-web-app-title" content="KISTA"/>
```

- [ ] **Step 4: 커밋 및 푸시**

```bash

git commit -m "feat(pwa): iOS 메타태그 및 manifest 링크 추가"

```
