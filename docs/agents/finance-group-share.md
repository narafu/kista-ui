# 가계부 그룹 공유 전환 — save-transaction·manage-budgets·manage-accounts·manage-categories·asset/save-asset 공통

- **그룹 공유 전환**: 개인 소유(`groupId` 없음) 거래내역·예산을 소유자의 현재 그룹으로 전환하는 `PATCH .../{id}/share`가 있다(`useShareFinanceTransactionMutation`/`useShareFinanceBudgetMutation`, 성공 시 각각 `transactionsRoot()`/`budgetsRoot()` 무효화). 역방향 `PATCH .../{id}/unshare`(`useUnshareFinanceTransactionMutation`/`useUnshareFinanceBudgetMutation`)도 있다 — 소유자 한정이 아니라 같은 그룹 멤버면 누구든 개인 소유로 되돌릴 수 있고, 되돌린 뒤 `userId`는 실행자가 아니라 기존 소유자 그대로 유지되며 이미 개인 소유면 멱등 200이다. 자산 스냅샷도 동일 패턴이다(`useShareAssetSnapshotMutation`/`useUnshareAssetSnapshotMutation`, `AssetSnapshotResponse.groupId`). `widgets/finance-record-list`·`widgets/asset-record-list`의 복제 버튼 옆, `manage-budgets/BudgetManager`의 수정 버튼 옆에 그룹 소속(`useFinanceGroupsQuery().length > 0`, `useCanShareToGroup()`) 상태에서 소유 형태에 따라 "공유"(`!item.groupId`) 또는 "귀속"(`item.groupId` 있음, 그룹 소유를 개인으로 되돌리는 버튼) 버튼 하나만 노출한다 — 무그룹 상태에서는 둘 다 없다. account는 `features/finance/manage-accounts/CLAUDE.md` 참고. category는 트리 구조라 `PATCH .../{id}/share`·`.../unshare`가 대상 노드 하위 전체(임의 depth)를 cascade로 함께 전환한다(kista-api recursive CTE 벌크 UPDATE). `useShareFinanceCategoryMutation`/`useUnshareFinanceCategoryMutation`(`entities/finance`)이 `categoriesRoot()` 무효화 방식(다른 category 뮤테이션과 동일 패턴)을 쓴다. `manage-categories/CategoryRow`가 `canShare`/`onShare`/`onUnshare` prop을 재귀로 하위까지 전달해 각 행이 자신의(서버가 이미 cascade 반영한) `groupId`를 그대로 렌더한다 — system 카테고리(`category.system`)는 그룹 개념이 없어 버튼 자체가 렌더되지 않는다. `SystemCategoryManager`는 이 prop들을 넘기지 않아 관리자 화면엔 노출되지 않는다. **신규 생성도 `POST /{resource}?shareToGroup=true` 한 번으로 그룹 소유로 원자적으로 만든다** (5개 리소스 공통). 대상 그룹은 서버가 `userId`로 해석하므로 클라가 groupId를 보내지 않는다. `BudgetForm`/`TransactionFormDialog`/`CategoryFormDialog`의 생성 모드와 `AssetForm`의 생성/복제 모드(`mode!=='edit'`), `AccountFormDialog` 생성 모드에 "그룹으로 저장" 스위치가 있다 — `useCanShareToGroup()`으로 게이팅, 기본값 켜짐, 체크 시 `useCreateXxxMutation` variables에 `shareToGroup: true`를 얹으면 `createXxx(data, { shareToGroup })` 단일 호출로 끝난다(부분 실패 상태 없음). 예산 그룹 기간 겹침(EXCLUDE 409)은 create 자체가 실패로 반환한다(`onError` → `apiMsg` 토스트); 개인 스코프 겹침은 서버가 규칙대로 자동 트림/삭제한다. **카테고리는 계층이라 부모가 개인 소유면 서버가 400** — `CategoryFormDialog`가 선택된 부모의 `groupId` 유무(`getCategoryPath(l1Categories, parentId).at(-1)`)로 토글을 게이팅해, 개인 부모 아래에서는 토글을 숨기고 "개인 카테고리 하위에는 그룹 공유 카테고리를 만들 수 없습니다" 안내를 띄운다. `widgets/finance-bulk-register`(일괄 등록)도 같은 `?shareToGroup=true`로 서버가 각 항목을 그룹 소유로 생성하며(항목별 실패는 응답 `failures[]`), 기본값도 단건 폼과 동일하게 그룹 소속이면 켜짐(`useState(true)`)이다.
