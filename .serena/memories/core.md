# kista-ui 코어

KISTA V2 — KIS API 기반 해외주식 자동 분할매매 초대제 멀티 사용자 SaaS 프론트엔드.

프로젝트 지식 SSOT는 `docs/agents/`다. 이 메모리들은 문서 포인터만 유지하고 내용을 중복 기재하지 않는다.

- 구조·라우팅·인증·FSD·기술 스택: `docs/agents/architecture.md` (요약 포인터: `mem:tech_stack`)
- 코딩 컨벤션·작업 규칙·Git: `docs/agents/constraints.md` (포인터: `mem:conventions`, `mem:task_completion`)
- API 계층·도메인 훅·DTO: `docs/agents/entities.md`, `docs/agents/shared.md` (포인터: `mem:api_layer`)
- Next.js·proxy·쿠키·SSE quirk: `docs/agents/app.md` (포인터: `mem:nextjs_quirks`)
- 컴포넌트·shadcn·CSS 토큰: `docs/agents/widgets.md` (포인터: `mem:components`)
- 명령어: `docs/agents/commands.md` (포인터: `mem:suggested_commands`)
- 배포·환경변수·Docker: `docs/agents/deployment.md`
